# Yük Ağı — tanıtım demosu

Lojistik firmalarına gösterilen tıklanabilir prototip. Tek dosya, bağımlılık yok.

Üst taraftaki "Demo rolü" menüsünden rol değiştirilir:

- **Pamukkale Lojistik** — firma yöneticisi: yük bul, ilanlar, teklifler, çalışanlar, QR
- **Ege Mermer** — yük veren: kendi ilanları ve gelen teklifler
- **Ergün Nakliyat** — nakliyeci: pazardaki yükler, verdiği teklifler, işleri
- **Platform yöneticisi** — onay kuyruğu, firmalar, abonelikler, gelir, işlem kayıtları

Sağ üstten TR/EN.

Veriler örnektir ve tarayıcıda tutulur; hiçbir şey kaydedilmez.
